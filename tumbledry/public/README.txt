Place your logo file in this folder named exactly: logo.png

Requirements:
- File name: logo.png  (exactly this name)
- Recommended size: 200x200px or square
- Format: PNG with transparent background works best

After adding logo.png:
1. Copy it to your repo's public/ folder
2. Commit and push via GitHub Desktop
3. Trigger deploy on Netlify

The logo will appear in the sidebar automatically.
